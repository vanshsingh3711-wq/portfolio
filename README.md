# Vansh Singh — Portfolio

Personal portfolio of **Vansh Sushil Singh**, AI Engineer, Backend Developer and Open-Source Contributor.

Showcases real-time voice streaming pipelines, deterministic cloud video rendering architectures, developer intelligence tooling, and open-source systems.

## Tech Stack

- **Framework**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS, custom design system
- **Animation**: GSAP, Framer Motion, Lenis Smooth Scroll
- **Graphics**: WebGL, GLSL Shaders, Canvas
- **Architecture**: Modular components, i18n (English & French), PWA offline support
- **Testing**: Vitest with React Testing Library

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run production build
npm run build

# Preview production build
npm run preview
```

## Featured Production Systems

- **Outreach**: Autonomous AI outbound prospecting platform with DeepSeek AI, Celery, Redis, and automated deliverability warmup.
- **AI Director**: Distributed cloud video production platform & deterministic Remotion rendering architecture on AWS (ECS, Fargate, SQS, FFmpeg).
- **Lucy**: Conversational shopping stylist powered by Model Context Protocol (MCP) and Shopify GraphQL API.
- **Lead Catcher**: Scalable, multi-tenant voice AI platform with Twilio WebSockets, Deepgram STT/TTS, and GPT-4o sub-second latency.
